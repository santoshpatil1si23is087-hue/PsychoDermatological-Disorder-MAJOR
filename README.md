# 🧠 Psychodermatological Disorder Detection & AI Health Assistant

An AI-powered web application that detects skin disorders and assesses mental health using deep learning (ResNet50) and clinical surveys (GAD-7 / PHQ-9), with personalized recommendations from Google Gemini AI.

---

## 🚀 How to Run Locally

```bash
# Install dependencies
pip install -r requirements.txt

# Start the server
python app.py
```
Open your browser at: **http://127.0.0.1:5000**

## 🤖 Tech Stack

- **Computer Vision:** ResNet50 (Fine-Tuned), VGG16, MobileNetV2, EfficientNetB0
- **Tabular ML:** Random Forest, Gradient Boosting, SVM, Logistic Regression
- **Generative AI:** Google Gemini 1.5 Flash/Pro, OpenAI GPT-4o Mini, Groq Llama-3 70B
- **Backend:** Python Flask
- **Frontend:** HTML, TailwindCSS, JavaScript
